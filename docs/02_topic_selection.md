## 결정: 월드비전

취업 포트폴리오 기준("고도화했을 때 할 줄 안다로 남는 요소가 가장 많은 것")으로 선택했다.

- RAG, 에이전트, LLMOps, 배포, 보안·거버넌스를 **모두** 다룰 수 있는 유일한 주제
- 개인정보 마스킹, 권한별 RAG, 토큰 비용 관리처럼 실제 기업이 사내 AI를 도입할 때 고민하는 부분을 다룬다
- RFP에 토큰 사용량 예시가 있어 비용 추정과 모델 선정 근거를 숫자로 쓸 수 있다
- 기능이 모듈처럼 나뉘어 있어 하나씩 쌓아 가며 고도화하기 쉽다

약점("흔한 사내 챗봇")은 KEA의 강점인 **라우터 에이전트 구조**를 얹어 보완한다.

## 도메인 확장 계획

산학 기업 수요조사 과제(공부용 참고) 중 월드비전 경험이 가장 많이 옮겨 가는 주제는 **산업안전 관리**다.

| 월드비전 기능 | 산업안전 버전 |
|---|---|
| 사내 규정 RAG | 산업안전보건법, KOSHA 가이드, 재해사례 RAG |
| 회의록 STT → 요약 → 메일 | 사고 음성 보고 → STT → 경위 정리 → 관리자 알림 |
| 보고서 생성 | 사고조사 보고서 (경위 → 원인 → 위반 법규 → 재발 방지 대책) |
| OCR | 안전점검표 OCR → 누락 항목 탐지 |
| (추가) | YOLO 위험 탐지 결과를 에이전트 툴로 호출 |

이를 위해 월드비전 구현 단계부터 도메인 의존 요소를 설정으로 분리한다.

| 분리할 것 | 월드비전 | 산업안전 |
|---|---|---|
| 문서 컬렉션 | 내부 규정, 매뉴얼 | 산업안전보건법, KOSHA 재해사례 |
| 시스템 프롬프트 | 사내 업무 도우미 | 안전관리 도우미 |
| 툴 목록 | 회의록, 일정, 보고서 | 사고 보고서, 법규 Q&A, 위험 탐지 |
| 보고서 템플릿 | 업무 보고서 | 사고조사 보고서 |
| 마스킹 규칙 | 아동명, 후원자명 | 작업자 이름, 얼굴 |
| 평가셋 | 사내 Q&A 50문항 | 법규 Q&A 50문항 |

포트폴리오에는 "산학 기업 수요조사 과제를 참고해 자체 수행"처럼 사실대로만 적는다.
